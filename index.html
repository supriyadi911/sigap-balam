Panduan Lengkap Penggunaan SIGAP BALAM

Selamat datang di aplikasi SIGAP BALAM (Sinergi Guru Aktif & Progresif Bandar Lampung). Berikut adalah rincian fungsionalitas menu berdasarkan peran (jabatan) akun Anda di dalam sistem:

A. Panduan Untuk Guru / Anggota

  • 1. Dashboard: Halaman ringkasan yang menampilkan statistik singkat, agenda terdekat, dan pengumuman terbaru.
  • 2. Profil & Struktur Organisasi: Menu untuk melihat Visi, Misi, dan Program Kerja dari tingkat Kota maupun Kecamatan, serta melihat daftar kecamatan yang terdaftar.
  • 3. Data Anggota: Melihat daftar rekan sejawat yang terdaftar dalam aplikasi. Anda bisa memfilter berdasarkan sekolah atau kecamatan.
  • 4. Tugas Anggota: Tempat Anda mengecek dan mengumpulkan tugas (seperti RPP, Nilai, dll) yang diminta oleh Admin Kecamatan. Cukup klik "Kumpul Tugas" dan tempelkan tautan (URL) dokumen Google Drive Anda.
  • 5. Agenda & Kegiatan: Kalender kegiatan komunitas. Klik "Detail" untuk melihat lokasi, waktu, kuota, atau tautan daring (seperti Google Meet).
  • 6. Pengumuman: Papan informasi penting dari pengurus kecamatan atau dinas pendidikan tingkat kota.
  • 7. Perpustakaan Materi: Sentra berbagi Modul Ajar, LKPD, dll. Anda bebas mengunduh materi milik guru lain, atau membagikan karya Anda sendiri. Anda juga bisa mengeklik tanda bintang (★) untuk menyimpan materi ke daftar favorit.
  • 8. Forum Diskusi: Ruang interaktif. Klik "Buat Topik Baru" jika Anda memiliki kendala di kelas, atau klik judul diskusi rekan lain untuk membalas dan memberikan solusi.

B. Panduan Untuk Admin Kecamatan

Admin Kecamatan memiliki semua akses menu Guru, ditambah wewenang pengelolaan berikut:

  • 1. Data Anggota (Approve/Edit): Admin kecamatan wajib mengecek menu ini secara berkala. Jika ada pendaftar baru bersatus Menunggu, klik tombol "Setujui" agar guru tersebut bisa Login. Admin juga bisa mengedit profil (termasuk mengganti password) anggota di wilayahnya.
  • 2. Tugas Komunitas: Menerima instruksi penugasan dari Admin Kota. Jika diminta mengumpulkan data tingkat kecamatan, gunakan menu ini untuk mengirim laporannya ke Kota.
  • 3. Tugas Anggota (Beri Tugas): Memberikan penugasan ke seluruh guru di kecamatan Anda. Anda dapat memantau siapa saja yang sudah mengumpulkan beserta tautan dokumennya.
  • 4. Agenda & Pengumuman: Anda memiliki tombol "+ Buat Kegiatan" dan "+ Buat Pengumuman" untuk mengatur agenda komunitas wilayah Anda sendiri.
  • 5. Laporan Kegiatan: Setiap selesai mengadakan kegiatan (lokakarya, KKG), Anda wajib membuat laporan (Tujuan, Hasil, Kendala, Dokumentasi) di menu ini lalu mengubah statusnya menjadi "Kirim untuk Ditinjau" agar diperiksa oleh Admin Kota.

C. Panduan Untuk Admin Kota (Super Admin)

Admin Kota adalah pengendali sistem (Super Admin) dengan hak penuh pada seluruh data di aplikasi:

  • 1. Profil & Struktur Organisasi: Dapat menambah, mengedit, atau menghapus daftar Kecamatan, serta mengubah Visi Misi tingkat Kota.
  • 2. Data Anggota (Global): Memiliki wewenang untuk meninjau, mengedit, mereset password, dan mengangkat status akun pengguna mana pun (termasuk menjadikan seseorang Admin Kecamatan).
  • 3. Tugas Komunitas (Terpusat): Anda dapat membagikan instruksi penugasan serentak ke seluruh Admin Kecamatan. Pada menu detail, Anda bisa melacak persentase pengumpulan (misal: 3/10 Terkumpul).
  • 4. Agenda & Pengumuman Publik: Dapat mengatur agenda dan pengumuman tingkat kota (Berdasarkan target, Anda bisa memilih agar pengumuman dilihat oleh semua guru atau khusus ditujukan untuk para Admin Kecamatan saja).
  • 5. Review Laporan Kegiatan: Menerima laporan dari kecamatan. Anda dapat memberikan status Setujui atau Kembalikan untuk Revisi beserta kolom catatan *(Feedback)*.
  • 6. Menu Pengaturan Aplikasi: Mengubah nama aplikasi, teks profil promosi di Landing Page (Halaman Depan), kontak *Footer*, menyisipkan kode statistik pengunjung (*Statcounter*), dan tombol bahaya "Reset Demo" (Hapus seluruh database).
Tips: Jika terjadi galat (error) atau aplikasi terasa tidak tersinkronisasi, perhatikan lampu indikator "Online/Offline" di sudut kanan atas layar Anda atau *refresh* halaman browser Anda.
